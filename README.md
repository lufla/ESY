# ESY git repository

This repository contains the digital appendix of the ESY project winter term 2025/26.

## Created files:

| Folder | Description |
|--------|-------------|
|[DE10-Nano-CAM](./DE10-Nano-CAM/) | Base board hardware files |
|[firmware/project](./firmware/project/) | Final project files|
|[firmware/hw_simple](./firmware/hw_simple/) | Description of software installation and the complete workflow to create the bitstream |
|[mechanical-design](./mechanical-design/) | 3D files for the mechanical case|
|[Doc](./Doc/) | Source file for the documentation |
|[firmware/hw_test](./firmware/hw_test/) | LED blinky used for all hardware testing |

## Files, that this project is based upon:

| Folder | Description |
|--------|-------------|
|[GateMateCode_Krause](./GateMateCode_Krause/) | Original codebase by Sven Krause adapted to the hardware of this project |
|[ulx5m-gs](./ulx5m-gs/) | SOM board hardware files |
|[Krause_Thesis.pdf](./Krause_Thesis.pdf) | Masters thesis by Sven Krause |
